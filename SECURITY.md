# Security Policy

## Supported versions

Security fixes are provided for the latest version published on the Visual Studio Marketplace.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/shishirui/phpdoc-comment-vscode-plugin/security/advisories/new) to report suspected vulnerabilities. Do not include exploit details, source code, credentials, or other sensitive information in a public issue.

Include the affected extension version, VS Code version, operating system, reproduction steps, and expected impact when available. You should receive an initial response within seven days.
